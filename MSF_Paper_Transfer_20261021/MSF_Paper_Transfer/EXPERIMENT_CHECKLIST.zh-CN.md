## 当前执行边界

现在只执行性能预检与配对性能筛查。下列消融、频谱、机制、能耗等项目均为清单，未投入 GPU 队列。论文表格数值不作为实测结果或复现成功标准。

## 第一阶段：性能

| 项目 | 设置 | 状态/产物 |
|---|---|---|
| 双数据集模型入口 | 同一 MSF-YOLOX 工程，GEN1 两极性时序输入；COCO 静态图像重复 T 次 | CPU 前向及检测损失反向已通过 |
| B0 | 新框架，固定衰减、多阈值 MSF 神经元，无新增 MaxSpikeFormer/FCBR/KCL | 已排队 |
| B1 | 严格二值 PLIF 替换 + 深层 MaxSpikeFormer + FCBR；GEN1 加 KCL | 已排队 |
| B2 | 保留多阈值 MSF 放电并学习衰减 + 深层 MaxSpikeFormer + FCBR；GEN1 加 KCL | 已排队；属于兼容性适配，不称为逐层等价的原论文实现 |
| GPU 预检 | 每个候选实际 320×320、T=5、batch=2，两个训练 batch | 等待现有 GPU 任务释放 |
| 配对筛查 | 每个数据集 B0/B1/B2，各 20 epoch，seed=1，累计 batch=8，FP32、从头训练 | 未开始；每 5 epoch 完整验证 |
| 指标 | AP50:95、AP50、AP75、尺寸分组 AP、参数量、训练耗时；之后测实际推理延迟/显存 | 无 AP 结果；不能以预检 loss 比较优劣 |
| 公平性核验 | 同划分/输入编码/尺寸/T/初始化来源/优化器/训练预算；保存配置、训练索引哈希、检查点、逐 epoch 指标 | 已实现基础记录；正式长跑前补完增强与训练策略审计 |
| 长程性能确认 | GEN1 250 epoch、COCO 300 epoch；同预算基线与最佳移植方案，独立训练，最终 3 seeds | 待筛查后决定；未自动启动 |
| 测试集确认 | GEN1 仅以验证集选模型，再对固定 test 评测；COCO 使用 val2017，需 test-dev 则单列 | 未启动 |

“效果非常好”尚未由用户给出数值阈值。建议预登记为：两数据集验证 AP50:95 各增加至少 1 个百分点，AP75 不明显退化，长程与多种子仍保持收益，同时报告参数和延迟变化。此为建议阈值，不是用户已确认标准。20 epoch 的负结果可能只是尚未收敛，不能单凭它否定方法或声称复现 SOTA。

当前筛查协议不是官方 SOTA 训练配方：320 输入、无外部预训练、无数据增强、20 epoch。用于检验代码与方向，不能拿筛查 AP 去直接比较论文中不同尺寸、预训练和充分训练的数字。需要官方配置同条件充分训练后才能讨论是否达到原基线水平。
