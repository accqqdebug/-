# PIT-SNNTrack：候选方法、证据链与叙事修订

日期：2026-10-11；目标：CVPR / ICCV / ECCV。本文是研究工作稿，尚非已证明的论文贡献。

## 研究边界与工具

使用 Nature Skills 的文献检索与算法论文论证流程；Codex Autoresearch 的只读适配结果为 continue-direct / assist-only。本轮完成代码审查、CPU 机制诊断、独立原型与研究叙事，不创建 Autoresearch 自动优化会话，不据此宣布任何候选胜出。现有 GPU 队列继续按既定顺序执行。

术语统一：事件分区指同一物理窗口内的内部切分；分区一致性指同一窗口不同切分后的预测一致程度；跟踪准确率以相对 GT 的 AUC 衡量。两者不能互换。残余膜状态指 LIF 发放与重置后的 v，不称为原始输入电位。物理终点摘要指在共同物理终点计算的事件统计，不称为整个网络的不变状态。

| 42 | +2.787 | +1.994 | +4.206 | +1.406 |
| 123 | -0.285 | -0.123 | -0.896 | +1.248 |
| 456 | -1.534 | -2.318 | -1.367 | -1.825 |
| 平均 | +0.323 | -0.149 | +0.647 | +0.276 |

一致性的序列 bootstrap 区间约为 [-3.706,+3.176] 个百分点。不能预设配对监督已经稳定有效，也不能把 full 的退步直接解释为状态约束破坏了运动。后者仍需要完整三种子结果与机制对照。

本轮完成的证据：

1. 使用实际 event_images 函数构造同事件反例：9 个事件在两种分区下的编码强度总和分别为 255 和 270。编码中的分箱后截断不满足可加性。
2. 按实际历史通道递推构造反例：同样两个事件、同样终点，历史值可以为 0 或 24。该反例说明历史递推依赖切分，不说明哪种切分的跟踪效果更好。
3. 抽查九条验证序列，每条四个均匀选取窗口，共 36 个窗口/策略。非零事件值的饱和比例仅约 0.064%—0.072%；jitter 相对 uniform 的聚合事件值相对 L1 差约 0.071%。因此去截断暂时是低优先级因素，不应被包装成主要性能瓶颈。
4. 相同抽样下，jitter 的终点历史通道平均绝对差约 0.770，fixed_count 约 0.486，均在 0—255 编码尺度上。该数量是全图均值，不能自动推断目标区域影响或准确率因果关系。
5. BNAndPadLayer 的独立模块反例确实有顺序效应，但它未接入当前 T4D1 的线性注意力路径。因此该反例不适用于解释当前模型。完整模型的合成同视图和一个真实训练样本同视图检查均得到零输出差、零状态损失。一个样本不足以排除其他情形，但已否定以该反例直接支撑模型因果解释的写法。
6. 物理终点线性摘要在 12 个分区/时间常数组合中通过守恒检查，包含空分箱和重复时间戳；指数统计最大浮点误差约 1.78e-15。只证明未量化摘要的可合并性，不证明非线性 SNN 或跟踪输出不变。

## 主线：从分区扰动的来源到任务约束的边界

建议的一句话研究问题是：当一个事件窗口包含完全相同的事件时，如何减少内部切分造成的无关定位变化，同时保留描述真实运动的时序信息？

论证应依次回答四个问题。第一，窗口等价是否成立，需要核对端点、事件集合及标签时间。第二，等价窗口为什么会产生不同表示，需要分离编码、历史递推和网络动态。第三，哪些差异应被约束，需要区分定位结果与允许变化的内部状态。第四，改进能否跨种子、跨分区和跨数据集成立，需要准确率、失败案例与成本共同验证。

这样可以把方法组织为一条连续因果假设，而不是三个互不相关的模块。归一化、梯度裁剪与随机深度首先是对照因素；只有产生可复现且可解释的新增能力时，才考虑进入核心贡献。

## 候选一：共同物理终点下可合并的事件摘要

动机：当前历史通道按分箱更新，事件的重现次数和历史衰减可能随切分改变。仅靠后端一致性损失，可能迫使网络补偿前端引入的变化。

机制：保留原始正负事件计数，并对每个极性计算共同终点 t_end 下的指数加权统计：M = sum exp(-(t_end-t_event)/tau)。每个分箱使用相同终点和相同 tau，未量化分箱统计相加应等于完整窗口统计。任何 log、裁剪或自适应尺度变换放在需要守恒的统计合并之后。若继续保留四个时序输入，各分箱仍不同；这里只固定可合并的宏观参考，不能称整个输入相同。

自然衔接：前端先提供明确的物理参考，后端再决定哪些任务信息必须保持一致。这样对齐的对象有可解释依据，而非任意隐藏特征。

实验：保持骨干、初始化与训练步数固定，先比较原历史通道、普通末次事件时间表面、物理终点摘要；再做摘要有/无 × 任务约束有/无的 2×2 对照。时间常数以窗口长度的固定比例设置，首先比较 0.5、1、2，不能使用测试结果选取。记录密度、运动与目标区域的差异，报告再编码耗时及存储成本。

否证：若简单时间表面同样有效，新的摘要不能主张超越既有表示；若摘要守恒但 GT AUC 无改善，只能保留为机制分析。若改善只来自删除历史通道，应报告这个更简单的解释。

状态：独立 CPU 原型已实现，尚未接入数据管线或 GPU 训练。需要重新生成训练专用缓存及匹配对照，当前数据盘空间不足以盲目展开。时间表面已有 HATS 等先例，不能宣称指数统计本身新颖。

## 候选二：可靠的任务空间分区一致性

动机：同一事件集合的两个分区并非都同样容易学习。无条件互相拉近可能传播差分支的误差；让所有残余膜状态相同又可能约束了任务并不要求相同的量。

机制：两分支都保持监督损失；训练标注只用于选择定位较可靠的停止梯度目标。对目标尺度归一化后的框和空间响应分布施加一致性；两分支都不可靠或质量差距不足时关闭额外约束；从零逐渐启用。推理不使用标注、第二分区或教师。

自然衔接：共同物理终点定义哪些窗口可以比较；可靠性判断决定哪些训练关系值得传递；任务空间约束决定需要稳定的是什么。内部脉冲动态仍有自由度。

实验：已封存的 symmetric、directional、gated 三组使用相同损失形式、权重和渐进日程。若门控表现良好，再比较 IoU 可靠性、响应熵可靠性及随机等比例门控，区分质量选择与减少正则化曝光量的作用。定向与对称的梯度分配不同，还需做系数匹配敏感性，不能把所有差异归因于方向性。

否证：一致性提升但 AUC 下降属于失败；随机等曝光门控同样有效时，不能主张质量选择机制；高运动子组趋势不能替代独立验证。SpikeFET 和 HDETrack 已有一致性/蒸馏先例，候选贡献应限于固定事件集合的分区关系及其可验证选择规则。

状态：训练损失和三组对照已在现有十组筛选队列中；尚未产生新性能结果。

## 候选三：保持时序关系的训练正则化与分区难度课程

动机：三种子结果的方向变化说明，降低训练波动可能与增加模块同样重要。常规逐时间片随机丢弃会改变四个时间片的对应关系；配对分支不同的随机掩码又会混入分区之外的扰动。

机制候选 A：对每个样本的整个时间轴共享残差路径掩码，通过配对 RNG 重放让两种分区共享掩码。正则化改变模型路径，同时保持比较关系。零丢弃率严格回到原路径，推理不丢弃。

机制候选 B：只在固定物理端点与事件集合内增加切分难度，比较固定、混合、渐进切分扰动。更难分区的选择若使用额外前向，必须配备同样计算预算的随机选择对照。

实验：随机深度先比较 0、0.05、0.1，必须先完成参数接线及 forward 实际调用；时间共享掩码与逐时间片独立掩码作为机制对照。课程必须匹配扰动总曝光量；不能把更长训练或更多前向当作课程贡献。

否证：若普通正则化同样有效，归为工程训练配方；若收益只是单个种子，不能宣称稳定；若课程损失低但未见分区泛化没有提高，则不进入主方法。

状态：时间共享随机深度独立原型通过 CPU 掩码检查；没有改动封存骨干，没有新增 GPU 训练。课程目前只有设计，尚未实现。随机深度和课程学习本身均为既有思想，不能用新的名称替代创新性证据。

## 可直接用于工作稿的叙事段落

事件流的时间切分是将异步观测输入离散网络的必要步骤，但切分边界并不总对应目标运动的变化。同一个物理窗口可以包含相同的事件，却因编码递推及网络时序处理产生不同表示。这引出一个具体问题：应如何减少由切分选择造成的定位波动，同时保留目标运动所需的动态信息？

现有工作分别改善事件表示、脉冲动态及特征一致性，为这一问题提供了基础。然而，表示的一致、内部状态的一致与定位结果的一致并非同一要求。我们的研究因此先建立同事件窗口下的受控比较，再检验哪些表示差异具有任务意义，避免将全部内部动态强制对齐。

基于这一问题，候选方法从共同物理终点的事件摘要出发，为跨分区比较提供可合并的参考；随后利用可靠的训练分支约束定位框与响应分布。训练正则化则共享时间与配对关系，尽量避免引入额外扰动。这些设计的有效性仍需通过公平消融、三种子复验及独立数据集判断，当前不写成已获得性能提升的结论。

实验叙事顺序应是：建立受控现象 → 检查编码来源 → 排除训练配方解释 → 比较约束对象 → 验证未见切分 → 独立基准及成本边界。full 的负结果和 seed456 的退步会改变论点，必须保留，不能藏入不显眼的补充材料。
